# 自动改进记录

## 2026-11-06（第一次）
**做了什么**
1. 首页按定稿设计重做：去掉开场页，打开就是歌单；顶部大字"唱准了"+右上圆形"练唱记录"按钮；"上次唱的 + 再唱一遍"卡片（有记录才显示）；每首歌一行大按钮，右边"唱"圆圈；"清唱/自己的伴奏/录好的歌"收成底部一行小字链接。
2. 唱歌画面：一句话提醒做成醒目的药丸（绿=准，橙=偏），"唱完了"改成大红按钮。
3. 结果页重排：总分圆环+评语 → 每一句（绿/橙+一句大白话怎么改，如"后半句低了一点，往上提"+听这一句）→ 按钮"听第 X 句（最需要练）/再唱一遍/回到歌单"。音高图、练法、AI 点评全部收进"更多详情"折叠里（功能没删）。
4. 练唱记录：加"这个星期唱了几次、进步几分"，每条改成歌名+时间+彩色分数+播放键。
5. 音高分析：修了"颤音唱法会被判成没听到音符"的问题（先平滑一个颤音周期再切音符）。
6. 唱歌时用屏幕常亮（Wake Lock），避免 iPhone 30 秒自动锁屏打断录音。
7. 新增 tools/test3.js：颤音、大颤音、气声、慢起音、低八度、整体偏低半音，共 7 种难情况，有断言。

**测试**：test.js、test2.js、test3.js 全部通过；用无头 Chrome 加载页面无 JS 报错，并用合成歌声跑通"分析→结果页"。注意：沙箱里没有中文字体，没法看真实截图，需要老板在 iPhone 上看一眼排版。

**没做/下一步建议**
- 设计稿里"大字歌词、已唱变金色"需要每首歌的歌词时间轴数据，目前歌词仍在 YouTube 视频里；建议下一步为几首常唱歌做歌词数据。
- "只练第 X 句"目前是"听这一句"，真正的"只唱这一句并循环"还没做。
- 唱歌画面的旋律条仍是原来的实时音高图，没完全换成设计稿的点阵样式。
- 竞品研究（唱吧/全民K歌/Smule/Yousician）这次没有做。

## 2026-11-06（第二次）
**做了什么**（这次沙箱有中文字体了，按 70 岁老人走了一遍 首页→选歌→唱→结果→记录 并看了截图）
1. 每句点评去掉简谱术语：以前写"「低音5」「低音6」「1」唱低了"，老人看不懂；现在写"开头和中间有 5 个字唱低了，往上提一点"/"句尾有 1 个字跑到别的音上了，多听两遍原唱这句"。（"更多详情"里和请老师点评里仍保留简谱，给懂的人看。）
2. 结果页按钮分主次：以前"听第 X 句（最需要练）""再唱一遍"、每句的"听这一句"全是金色大按钮，眼花不知道点哪个；现在只有"听第 X 句"是金色，其它改成金色描边，带播放三角。
3. 唱歌画面按设计稿：去掉大号 0:18 计时，改成一行小字"● 正在听您唱 · 0:18"（红点慢慢闪），位置让给带歌词的视频；原来标题前也有个红点，重复了，去掉；提示药丸里中性状态不再是灰字（以前像按钮被禁用），"在听…"改成"正在听，放心唱"。
4. 选歌页去掉"mp3"：卡片改成"手机里有这首歌？ [从手机选]"，出错提示也不提 mp3/m4a。
5. 音高测试 test3.js 加了 4 种难情况：基频很弱（最容易错八度）、女高音区、男低音区、两个长音唱高 60 音分（确认能抓出来）。全部通过，说明八度和音区这块目前稳。

**测试**：test.js、test2.js、test3.js 全部通过；walk.py 走查无 JS 报错。

**观察 / 下一步建议**
- 唱两个音高了 60 音分，总分还有 94，偏宽松；可以考虑适当收紧（要老板觉得"分数要鼓励为主"还是"要严一点"）。
- 【方案，待老板定】"只练第 X 句"：点了以后视频跳到这句前 2 秒开始放，只录这一句，唱完自动停、马上给这一句打分，可以反复练。难点是录音时间和视频时间要对齐（目前只知道录音开始时刻），需要记下开始录音时视频的播放位置。改动中等，建议下次单独做。
- 竞品做法（凭经验整理，未联网核实）：唱吧/全民K歌唱的时候每句结束立刻弹出"完美/好/一般"并累计连击，结果页按句给分可单句重唱；Smule 以伴奏+歌词滚动为主，打分弱；Yousician 每个音的"准/早/晚/高/低"颜色反馈非常即时。值得学：①每句唱完马上一个大字评价（我们已有提示药丸，可在句尾加"这句 ✓ 很准"）；②单句重唱（即上面的方案）。
- 设计稿里的"大字歌词、已唱变金色"仍需要歌词时间轴数据，目前歌词在视频里。

## 2026-11-06（第三次）
**做了什么**：做了老板拍板的"只练这一句"。
1. 唱整首时，记下"开始录音那一刻视频播到第几秒"，结果里每句就能对上视频位置（存进 R.yt，旧记录没有这个信息就不显示新按钮）。
2. 结果页：每句"还不错/要多练"的卡片里加了金色大按钮"只练这一句"；底部主按钮从"听第 X 句"变成"只练第 X 句（最需要练）"。
3. 点了以后：视频自动跳到这句前 2.5 秒开始放（带歌手声音的那版视频，不用 mp3 对齐，最稳），只录这一句，句尾过 1 秒自动停，马上出这句的分数。顶部返回链接变成"‹ 回到结果"。
4. 单句结果页：大字分数 + 一句话（"✓ 这句唱准了"或"低了一点，往上提"）+ "比之前的 88 分进步了 7 分，真棒！" + 小音条图；按钮"再练这一句 / 听我刚唱的 / 回到整首歌的结果"。单句练习不写进练唱记录，回去后整首结果原样恢复。
5. 音高分析加了可选参数：单句很短，放宽"至少 4 秒歌声、5 个音"的门槛；没听清时友好提示"离手机近一点，再唱一次"，不报错。
6. walk.py 走查加了单句练习两步截图。

**测试**：test.js / test2.js / test3.js 全部通过；手机尺寸走查 首页→唱→结果→只练第 3 句→单句结果→回到结果→记录，无 JS 报错，截图确认排版正常。

**下一步建议**

- 用了自己 mp3 原唱的歌，单句练习目前用视频原声，没有伴奏音条；以后可做 mp3 从这句开始放。
- 单句分数 95 但仍提示"低了一点"（符合"分数宽松、问题照说"的原则），观察老人会不会困惑。
- 设计稿里的大字歌词、竞品研究仍待做。
