# 自动改进记录

## 2026-11-06（第一次）
**做了什么**
1. 首页按定稿设计重做：去掉开场页，打开就是歌单；顶部大字"唱准了"+右上圆形"练唱记录"按钮；"上次唱的 + 再唱一遍"卡片（有记录才显示）；每首歌一行大按钮，右边"唱"圆圈；"清唱/自己的伴奏/录好的歌"收成底部一行小字链接。
2. 唱歌画面：一句话提醒做成醒目的药丸（绿=准，橙=偏），"唱完了"改成大红按钮。
3. 结果页重排：总分圆环+评语 → 每一句（绿/橙+一句大白话怎么改，如"后半句低了一点，往上提"+听这一句）→ 按钮"听第 X 句（最需要练）/再唱一遍/回到歌单"。音高图、练法、AI 点评全部收进"更多详情"折叠里（功能没删）。
4. 练唱记录：加"这个星期唱了几次、进步几分"，每条改成歌名+时间+彩色分数+播放键。
5. 音高分析：修了"颤音唱法会被判成没听到音符"的问题（先平滑一个颤音周期再切音符）。
6. 唱歌时用屏幕常亮（Wake Lock），避免 iPhone 30 秒自动锁屏打断录音。
7. 新增 tools/test3.js：颤音、大颤音、气声、慢起音、低八度、整体偏低半音，共 7 种难情况，有断言。

**测试**：test.js、test2.js、test3.js 全部通过；用无头 Chrome 加载页面无 JS 报错，并用合成歌声跑通"分析→结果页"。注意：沙箱里没有中文字体，没法看真实截图，需要老板在 iPhone 上看一眼排版。
