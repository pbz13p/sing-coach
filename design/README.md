# 唱准了 · 定稿设计（2026-11-06）

4 个画面，手机 390×844：Main（首页选歌）→ Sing（唱歌中）→ Result（结果）→ History（练唱记录）。
这些 .dc.html 是设计稿（Claude Design 画布），不是上线代码：照着它的布局、颜色、字号、文案，在 page.html 里实现。
画布：https://claude.ai/artifact/Ya9eF6NwvKcaZN24F2oFNf

原则（老板拍板）：简单、直接、好看。
- 打开就是歌单，点一首就开唱；最上面是"上次唱的 + 再唱一遍"。
- 唱的时候只有三样：旋律条+音高点（绿=准，橙=偏）、一句大白话提醒、大字歌词（已唱部分变金色）。
- 唱完：总分圆环 + 一句评语；每一句绿/橙 + 怎么改 + 听这一句；主按钮"只练第 X 句"（自动挑最差的一句），次按钮"回到歌单"。
- 颜色：底 #0d1626，卡片 #142238，正文 #f4efe6，次要 #9aa6b8，香槟金 #d8bf8f，好 #7fd1ae，偏 #e9b872，停止 #ee8574。
- 字体：标题 Noto Serif SC，正文 Noto Sans SC；正文 ≥17px，按钮 ≥46px 高。
- 去掉一切多余的步骤、说明文字和设置；功能不删，收进次要位置。
